A complete story in exactly six words, written for make.fun's "Six Words, One Story" bounty ($5 pool: 1st $2, 2nd $2, 3rd $1):

> Mars called. Earth let it ring.

Six words, one missed call from another world — contact, hope, and indifference in a single unanswered ring. Pure Python standard library, deterministic, no network.

## Run it

```sh
python3 main.py
```

Writes the story to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), guarded by `validate_story()`: exactly 6 words, a single line, 1–60 Unicode code points.
